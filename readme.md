## Features

- DIU portal-inspired dashboard UI
- Editable semester results
- CGPA simulation
- Local-only data storage
- Offline support
- Responsive design
- PWA support
- Fast Vercel deployment

---

## 🛠 How It Works

The application runs entirely on the client side.

### Data Handling

- Uses browser `localStorage`
- No backend/database
- No external API calls
- No university system integration

### Important

Clearing browser storage may erase locally saved demo data.
